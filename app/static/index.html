Rate card — rows are locked until you click Edit; set Title, both rates & currency ($/£/CA$) together, then Save. Apply pushes rates to every resource using the title.
“Apply” pushes one title's rates; “Update All Pricing” pushes every title.
Who is on each title lives in the Used By column. To change capacity — the number that decides over/under-utilization — go to Utilization.
People — every person exists once, with a home title, approved titles and a weekly capacity. PMs pick from this list and can never invent a name or a rate. Merging split records here keeps the 100% rule honest.
Recent activity — merges, deletes and rate pushes, newest first. Recorded on the server, so nothing is missed even if the browser is closed.
Billable OT approvals — a PM can flag OT as billable, but the money only reaches the Dashboard once you approve it here.
Project managers — create a PM and tick the clients/projects they may record actuals for. A PM only ever sees their own projects, and never sees rates.
Admin management — create admin accounts and choose which admin options each one gets. the owner stays the biggest admin (full access, cannot be removed). Only the owner can add/edit/delete admins.
Database Security — the finance database is encrypted with SQLCipher. Set or change the DB password here (protects the data at rest).
